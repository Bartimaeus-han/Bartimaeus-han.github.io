쓰는 곳

그 권한은 교회 유튜브 채널에 예배 영상을 올리고, 올린 영상의 제목·설명·공개 설정을 바꾸는 데만 씁니다. 다른 목적에는 쓰지 않습니다.

보관과 공유

토큰은 프로그램이 도는 교회 컴퓨터 한 대에만 저장되고, 어떤 서버로도 보내지 않으며 누구와도 나누지 않습니다. Google 사용자 데이터를 광고, 판매, 다른 서비스로 옮기는 데 쓰지 않습니다.

Google API 에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.
